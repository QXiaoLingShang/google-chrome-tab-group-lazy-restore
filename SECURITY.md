# Security

Please report a suspected vulnerability through the repository's GitHub private vulnerability reporting feature if it is enabled. Otherwise contact the maintainer using a contact method listed on their GitHub profile. Do not post private browsing data or an exploitable vulnerability in a public issue.

Include the extension version, Chrome version, reproduction steps with synthetic URLs, impact, and a suggested fix if available. No response-time commitment is currently made; this is a volunteer-maintained project.

Only the current release is maintained. Updates should preserve minimal permissions and use Chrome's own tab-discard API. Dependency updates must pass the same verification as other changes.
